# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML5, CSS3, JavaScript, and Bootstrap**. This project provides a clean and user-friendly shopping experience with product browsing, cart management, and responsive layouts. It demonstrates frontend development skills, interactive UI design, and client-side data persistence using Local Storage.

## 🚀 Features

* Responsive homepage design
* Product listing and showcase section
* Product detail pages
* Shopping cart functionality
* Category-based product navigation
* Mobile-friendly interface
* Interactive user experience
* Persistent cart data using Local Storage
* Modern and attractive UI design

## 💾 Local Storage Integration

The application uses the browser's **Local Storage API** to store and manage shopping cart data on the client side.

### Benefits

* Cart items remain available after page refreshes
* Data persists even when the browser is reopened
* No backend or database required for cart management
* Faster and seamless user experience
* Lightweight client-side storage solution

## 🛠️ Technologies Used

* **JavaScript (ES6+)** – Dynamic functionality and Local Storage management
* **Bootstrap** – Responsive design and UI components
