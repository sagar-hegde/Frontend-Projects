# 🍔 Food Delivery Website

A modern and responsive Food Delivery Website built using HTML5, CSS3, JavaScript, and Bootstrap. This project provides a seamless online food ordering experience where users can explore restaurants, browse menus, search for meals, and discover food categories through an interactive and user-friendly interface. It demonstrates frontend development skills, responsive design principles, and dynamic user interactions.

## 🚀 Features

* Restaurant and menu browsing
* Food categories and filtering
* Search functionality for meals and restaurants
* Interactive UI components
* Responsive homepage design
* Mobile-friendly interface
* Dynamic user experience
* Attractive and modern design
* Easy navigation and user-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and layout
* **JavaScript (ES6+)** – Dynamic functionality and interactivity
* **Bootstrap** – Responsive design and UI components

## 🎯 Project Objectives

* Build a responsive food ordering platform
* Practice frontend web development concepts
* Create reusable and maintainable UI components
* Enhance user experience through intuitive navigation
* Implement dynamic search and filtering functionality
* Demonstrate Bootstrap-based responsive layouts

## 📱 Responsive Design

The website is fully responsive and optimized for:

* 💻 Desktop Devices
* 📱 Mobile Phones
* 📟 Tablets
