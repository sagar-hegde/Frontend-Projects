# 🎟️ Museum Ticketing System

A modern and responsive Museum Ticketing System built using HTML5, CSS3, JavaScript, and Bootstrap. This project provides a seamless online ticket booking experience for museum visitors, allowing them to explore museum information, select visit dates, choose the number of visitors, and book tickets through an intuitive and user-friendly interface. It demonstrates frontend development skills, responsive design principles, and interactive form handling.

## 🚀 Features

- Museum information display
- Online ticket booking interface
- Visit date selection
- Visitor count selection
- Interactive booking forms
- Responsive user interface
- Mobile-friendly design
- Easy navigation and user-friendly layout
- Modern and attractive design
- Smooth user experience

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and layout
- **JavaScript (ES6+)** – Form validation and interactivity
- **Bootstrap** – Responsive design and UI components

## 🎯 Project Objectives
