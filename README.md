# 🚀 Frontend Projects

A collection of responsive and user-friendly frontend web applications built using **HTML5, CSS3, JavaScript, and Bootstrap**. These projects demonstrate strong fundamentals in web development, responsive design, UI/UX implementation, and client-side functionality.

## 📌 Projects Included

### 1. 🛒 E-Commerce Website

A modern online shopping platform designed to provide a seamless shopping experience.

**Features:**

* Responsive homepage and product listings
* Product detail pages
* Shopping cart interface
* Category-based navigation
* Attractive and user-friendly UI

**Technologies Used:** HTML, CSS, JavaScript, Bootstrap

### 2. 🍔 Food Delivery Website

A responsive food ordering platform that allows users to explore restaurants and order meals online.

**Features:**

* Interactive UI components
* Mobile-friendly design
* Dynamic user experience

**Technologies Used:** HTML, CSS, JavaScript, Bootstrap

### 3. 🥬 Grocery Website

An online grocery shopping website focused on simplicity and ease of use.

**Features:**
